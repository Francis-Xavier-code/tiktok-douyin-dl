# 下载地址

> [!IMPORTANT]
> macOS DMG、iOS IPA、Android APK 和 Windows 安装包目前未使用商业代码签名。请只从本仓库 Release 下载，并核对发布来源。iOS IPA 需要使用你自己的 Apple ID 或开发者证书签名后安装。

## Windows（Windows 10/11，x64）

### 正常安装版（推荐）

- [Windows x64 安装包](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.0/MediaDownloader-Windows-x64-Setup-2.0.0.exe)

### 命令行版

- [Windows x64 CLI](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.0/MediaDownloader-Windows-x64-CLI-2.0.0.zip)

  也可用一键安装脚本：

  ```powershell
  irm https://raw.githubusercontent.com/Francis-Xavier-code/tiktok-douyin-dl/main/install.ps1 | iex
  ```

CLI 会根据分享链接自动识别抖音或 TikTok；带 `modal_id` 的抖音搜索结果链接也会自动转换为直接作品链接：

```powershell
media-downloader.exe "分享文本或链接"
```

## macOS

### 图形界面

- [Apple 芯片 / Intel 芯片通用版](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.0/MediaDownloader-macOS-2.0.0-unsigned.dmg)

将 `MediaDownloader.app` 拖入"应用程序"。首次运行如被 Gatekeeper 阻止，请前往"系统设置 → 隐私与安全性 → 仍要打开"。

### 命令行版

- [Apple 芯片 CLI](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.0/MediaDownloader-macOS-arm64-CLI-2.0.0.zip)

也可用一键安装脚本（自动按架构下载并解除 quarantine）：

```bash
curl -fsSL "https://raw.githubusercontent.com/Francis-Xavier-code/tiktok-douyin-dl/main/install.sh" | bash
```

## Android

- [douyin-download Android APK](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.0/douyin-download-Android-2.0.0.apk)

下载后安装到手机（需允许「安装未知来源应用」）。支持抖音与 TikTok 无水印下载、远程策略验签与更新检查。

## iOS / iPadOS

- [未签名 IPA](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.0/MediaDownloader-iOS-2.0.0-unsigned.ipa)

IPA 不能直接在未越狱设备上安装，需要通过 Xcode、AltStore、SideStore 或其他可信工具使用你自己的 Apple ID 重新签名。

## Linux（x86_64）

### 便携 CLI 压缩包

- [Linux x86_64 CLI](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.0/MediaDownloader-Linux-x86_64-2.0.0.tar.gz)

安装后只需要一个命令，程序会根据链接域名自动识别平台，并兼容带 `modal_id` 的抖音搜索结果链接：

```bash
media-downloader "分享文本或链接"
```

也可以运行一键安装脚本：

```bash
curl -fsSL "https://raw.githubusercontent.com/Francis-Xavier-code/tiktok-douyin-dl/main/install.sh" | bash
```

## v2.0.0 更新内容

完整的更新记录见 [CHANGELOG.md](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/blob/main/CHANGELOG.md)。

### 新增

- **全平台版本号统一管理**：新增 `version.json` 作为所有端版本号的唯一事实来源，`scripts/sync-versions.py` 一键同步到全部硬编码位置，`release.sh` 发版前自动同步。
- **共享按端过滤更新日志**：新增机器可读的 `changelog.json`（由 CHANGELOG.md 自动生成），CLI / Windows GUI / macOS / iOS / Android 检查更新时自动拉取并按端显示本端相关更新内容。
- **Windows GUI 重构**：粘贴链接自动识别平台（去除手动下拉框）、整体 UI 美化（横幅/徽标/彩色日志）、更新弹窗改为可滚动更新日志对话框并修复线程弹窗失效。
- **macOS 检查更新**：主窗口与菜单栏新增「检查更新」，显示本端更新日志。
- **macOS CLI 打包**：PyInstaller 单文件，Apple 芯片（arm64）架构；`install.sh` 一键安装脚本支持 Linux 与 macOS。
- **CLI 内置无头浏览器**：所有 CLI 产物随包附带 headless Chromium 侧车，首次运行无需联网下载。
- **Android 客户端**：抖音与 TikTok 解析/下载、远程策略 Ed25519 验签（fail-closed）、自动更新检查与按端更新日志，版本号与主版本线对齐。
- **AI Skill 一句话指令**：README 提供复制即用的一句话提示词，AI 自行读取技能文件即可下载。

### 修复

- **iOS 更新检测失效**：原来查找不存在的 `ios-v*` 标签，永远检测不到更新；改为读取共享 changelog.json。
- **CLI 打包版不检查更新**：统一入口 `media-downloader` 启动时新增静默更新提示并显示本端更新日志。
- **Agent Skill 安装失败**：原来下载不存在的裸二进制资产，改为下载官方归档并支持 macOS。
