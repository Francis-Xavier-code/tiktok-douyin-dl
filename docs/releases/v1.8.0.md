# 下载地址

> [!IMPORTANT]
> macOS DMG、iOS IPA 和 Windows 安装包目前未使用商业代码签名。请只从本仓库 Release 下载，并核对发布来源。iOS IPA 需要使用你自己的 Apple ID 或开发者证书签名后安装。

## Windows（Windows 10/11，x64）

### 正常安装版（推荐）

- [Windows x64 安装包](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.8.0/MediaDownloader-Windows-x64-Setup-1.8.0.exe)

### 命令行版

- [Windows x64 CLI](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.8.0/MediaDownloader-Windows-x64-CLI-1.8.0.zip)

CLI 会根据分享链接自动识别抖音或 TikTok；带 `modal_id` 的抖音搜索结果链接也会自动转换为直接作品链接：

```powershell
media-downloader.exe "分享文本或链接"
```

## macOS

- [Apple 芯片 / Intel 芯片通用版](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.8.0/MediaDownloader-macOS-1.8.0-unsigned.dmg)

将 `MediaDownloader.app` 拖入“应用程序”。首次运行如被 Gatekeeper 阻止，请前往“系统设置 → 隐私与安全性”确认打开。

## iOS / iPadOS

- [未签名 IPA](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.8.0/MediaDownloader-iOS-1.8.0-unsigned.ipa)

IPA 不能直接在未越狱设备上安装，需要通过 Xcode、AltStore、SideStore 或其他可信工具使用你自己的 Apple ID 重新签名。

## Linux（x86_64）

### 便携 CLI 压缩包

- [Linux x86_64 CLI](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.8.0/MediaDownloader-Linux-x86_64-1.8.0.tar.gz)

安装后只需要一个命令，程序会根据链接域名自动识别平台，并兼容带 `modal_id` 的抖音搜索结果链接：

```bash
media-downloader "分享文本或链接"
```

也可以运行一键安装脚本：

```bash
curl -fsSL "https://raw.githubusercontent.com/Francis-Xavier-code/tiktok-douyin-dl/main/install.sh" | bash
```

## v1.8.0 更新内容

完整的更新记录见 [CHANGELOG.md](../../CHANGELOG.md)。

- **远程版本策略（停用旧版本）正式发布**：由 GitHub 托管的 `version-policy.json`，维护者可以在**不重新编译/重新发布各端安装包**的前提下，远程控制哪些旧版本被提示升级或拒绝运行。各端启动时拉取该文件（失败则放行，绝不影响正常使用），与自身版本号比对：
  - **软提示（默认）**：低于 `min_version` 时弹窗/横幅提醒升级，但旧版本仍可使用。
  - **硬阻挡**：对应平台 `hard_block: true` 时，低于 `min_version` 直接拒绝运行，仅显示升级提示与下载链接。
  - 覆盖端：CLI / macOS / Linux（Python 核心 `core/version_policy.py`）、Windows GUI（`auto_updater.enforce_version_policy`）、iOS 与 macOS 菜单栏（各自的 `VersionPolicyService`）。
  - `scripts/release.sh` 会在发布时自动刷新 `updated_at` 并把策略文件作为 Release 产物上传。详见 `docs/version-policy.md`。
  - 注意：本项目是无后端的纯客户端，已发布且不含本机制的旧版本无法被远程杀掉——本机制仅对未来包含版本检查的新构建生效。
- 全平台版本号统一为 `1.8.0`。
