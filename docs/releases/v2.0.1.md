# 下载地址

> [!IMPORTANT]
> macOS DMG、iOS IPA、Android APK 和 Windows 安装包目前未使用商业代码签名。请只从本仓库 Release 下载，并核对发布来源。iOS IPA 需要使用你自己的 Apple ID 或开发者证书签名后安装。

## Windows（Windows 10/11，x64）

### 正常安装版（推荐）

- [Windows x64 安装包](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.1/MediaDownloader-Windows-x64-Setup-2.0.1.exe)

### 命令行版

- [Windows x64 CLI](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.1/MediaDownloader-Windows-x64-CLI-2.0.1.zip)

  也可用一键安装脚本：

  ```powershell
  irm https://raw.githubusercontent.com/Francis-Xavier-code/tiktok-douyin-dl/main/install.ps1 | iex
  ```

CLI 会根据分享链接自动识别抖音或 TikTok；带 `modal_id` 的抖音搜索结果链接也会自动转换为直接作品链接：

```powershell
media-downloader.exe "分享文本或链接"
```

## macOS

### 图形界面

- [Apple 芯片 / Intel 芯片通用版](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.1/MediaDownloader-macOS-2.0.1-unsigned.dmg)

将 `MediaDownloader.app` 拖入"应用程序"。首次运行如被 Gatekeeper 阻止，请前往"系统设置 → 隐私与安全性 → 仍要打开"。

### 命令行版

- [Apple 芯片 CLI](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.1/MediaDownloader-macOS-arm64-CLI-2.0.1.zip)

也可用一键安装脚本（自动按架构下载并解除 quarantine）：

```bash
curl -fsSL "https://raw.githubusercontent.com/Francis-Xavier-code/tiktok-douyin-dl/main/install.sh" | bash
```

## Android

- [douyin-download Android APK](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.1/douyin-download-Android-2.0.1.apk)

下载后安装到手机（需允许「安装未知来源应用」）。支持抖音与 TikTok 无水印下载、远程策略验签与更新检查。

## iOS / iPadOS

- [未签名 IPA](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.1/MediaDownloader-iOS-2.0.1-unsigned.ipa)

IPA 不能直接在未越狱设备上安装，需要通过 Xcode、AltStore、SideStore 或其他可信工具使用你自己的 Apple ID 重新签名。

## Linux（x86_64）

### 便携 CLI 压缩包

- [Linux x86_64 CLI](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v2.0.1/MediaDownloader-Linux-x86_64-2.0.1.tar.gz)

安装后只需要一个命令，程序会根据链接域名自动识别平台，并兼容带 `modal_id` 的抖音搜索结果链接：

```bash
media-downloader "分享文本或链接"
```

也可以运行一键安装脚本：

```bash
curl -fsSL "https://raw.githubusercontent.com/Francis-Xavier-code/tiktok-douyin-dl/main/install.sh" | bash
```

## v2.0.1 更新内容

完整的更新记录见 [CHANGELOG.md](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/blob/main/CHANGELOG.md)。

### 新增

- **[CLI]** 统一入口 `media-downloader` 支持自动更新：启动时静默检测新版本并打印本端更新日志（changelog.json 镜像，fail-open）；打包版（frozen）检测到新版本时自动下载并替换自身二进制，源码运行仅提示不替换。

### 修复

- **[CLI]** 修复在线安装脚本显示异常的问题。
- **[Windows]** 修复 GUI 中「打开文件夹」按钮显示成函数的问题。
- **[全平台]** 修复版本号同步遗漏：`scripts/sync-versions.py` 现在也会同步构建脚本与 About 弹窗中的版本兜底值，确保全仓版本号统一为 2.0.1。
