# 下载地址

> [!IMPORTANT]
> macOS DMG、iOS IPA 和 Windows 安装包目前未使用商业代码签名。请只从本仓库 Release 下载，并核对发布来源。iOS IPA 需要使用你自己的 Apple ID 或开发者证书签名后安装。

## Windows（Windows 10/11，x64）

### 正常安装版（推荐）

- [Windows x64 安装包](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.8.2/MediaDownloader-Windows-x64-Setup-1.8.2.exe)

### 命令行版

- [Windows x64 CLI](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.8.2/MediaDownloader-Windows-x64-CLI-1.8.2.zip)

CLI 会根据分享链接自动识别抖音或 TikTok；带 `modal_id` 的抖音搜索结果链接也会自动转换为直接作品链接：

```powershell
media-downloader.exe "分享文本或链接"
```

## macOS

- [Apple 芯片 / Intel 芯片通用版](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.8.2/MediaDownloader-macOS-1.8.2-unsigned.dmg)

将 `MediaDownloader.app` 拖入"应用程序"。首次运行如被 Gatekeeper 阻止，请前往"系统设置 → 隐私与安全性"确认打开。

## iOS / iPadOS

- [未签名 IPA](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.8.2/MediaDownloader-iOS-1.8.2-unsigned.ipa)

IPA 不能直接在未越狱设备上安装，需要通过 Xcode、AltStore、SideStore 或其他可信工具使用你自己的 Apple ID 重新签名。

## Linux（x86_64）

### 便携 CLI 压缩包

- [Linux x86_64 CLI](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.8.2/MediaDownloader-Linux-x86_64-1.8.2.tar.gz)

安装后只需要一个命令，程序会根据链接域名自动识别平台，并兼容带 `modal_id` 的抖音搜索结果链接：

```bash
media-downloader "分享文本或链接"
```

也可以运行一键安装脚本：

```bash
curl -fsSL "https://raw.githubusercontent.com/Francis-Xavier-code/tiktok-douyin-dl/main/install.sh" | bash
```

## v1.8.2 更新内容

完整的更新记录见 [CHANGELOG.md](../../CHANGELOG.md)。

### 新增

- **全平台版本号显示**：CLI 启动时显示版本号并支持 `--version` / `-V` 参数；Windows 标题栏显示版本号；macOS 主窗口和菜单栏显示版本号。
- **全平台免责声明同意弹窗**：CLI、iOS、macOS 首次运行均显示完整免责声明弹窗，支持「下次不再提示」并持久化。
- **macOS 静默自动更新**：版本被硬阻挡时自动检查 GitHub releases、下载 DMG 并打开 Finder 安装界面。
- **CLI (Linux) 静默自动更新**：frozen 二进制在 silent 模式下自动下载新版本并替换自身。

### 修复

- **macOS AppUpdateService.swift 编译错误**：`dropFirst` 参数类型修复。

### 强制更新

- **全平台版本策略升级**：`version-policy.json` 设置所有平台 `min_version: 1.8.2`，`hard_block: true`。1.8.1 及以下版本启动时将被强制拦截，提示升级。
