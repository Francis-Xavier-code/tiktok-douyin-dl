# 下载地址

> [!IMPORTANT]
> macOS DMG、iOS IPA 和 Windows 安装包目前未使用商业代码签名。请只从本仓库 Release 下载，并核对发布来源。iOS IPA 需要使用你自己的 Apple ID 或开发者证书签名后安装。

## Windows（Windows 10/11，x64）

### 正常安装版（推荐）

- [Windows x64 安装包](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.7.0/MediaDownloader-Windows-x64-Setup-1.7.0.exe)

### 命令行版

- [Windows x64 CLI](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.7.0/MediaDownloader-Windows-x64-CLI-1.7.0.zip)

CLI 会根据分享链接自动识别抖音或 TikTok：

```powershell
media-downloader.exe "分享文本或链接"
```

## macOS

- [Apple 芯片 / Intel 芯片通用版](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.7.0/MediaDownloader-macOS-1.7.0-unsigned.dmg)

将 `MediaDownloader.app` 拖入“应用程序”。首次运行如被 Gatekeeper 阻止，请前往“系统设置 → 隐私与安全性”确认打开。

## iOS / iPadOS

- [未签名 IPA](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.7.0/MediaDownloader-iOS-1.7.0-unsigned.ipa)

IPA 不能直接在未越狱设备上安装，需要通过 Xcode、AltStore、SideStore 或其他可信工具使用你自己的 Apple ID 重新签名。

## Linux（x86_64）

### 便携 CLI 压缩包

- [Linux x86_64 CLI](https://github.com/Francis-Xavier-code/tiktok-douyin-dl/releases/download/v1.7.0/MediaDownloader-Linux-x86_64-1.7.0.tar.gz)

安装后只需要一个命令，程序会根据链接域名自动识别平台：

```bash
media-downloader "分享文本或链接"
```

也可以运行一键安装脚本：

```bash
curl -fsSL "https://raw.githubusercontent.com/Francis-Xavier-code/tiktok-douyin-dl/main/install.sh" | bash
```
